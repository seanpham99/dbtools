# Security Policy

## Supported Versions

We actively maintain and support security fixes on the latest minor release branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in `dbtools`, please do **NOT** open a public issue.

Instead, please report security issues through GitHub Private Vulnerability Reporting:
1. Navigate to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Provide details about the vulnerability, reproduction steps, and potential impact.

Alternatively, you can email security reports directly to the maintainer at `seanpham99@gmail.com`.

### Response Timeline

- **Initial Acknowledgement**: Within 48 hours.
- **Triage and Assessment**: Within 5 business days.
- **Fix and Disclosure**: Security patches are released as point releases along with CVE advisories when applicable.
